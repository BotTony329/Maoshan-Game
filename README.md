# 茅山幸存者（Maoshan Survivors）

茅山道士题材的《吸血鬼幸存者》式弹幕 rogue-like：WASD 走位，法器全自动，拾魂升级，撑过一炷香（15 分钟）天亮即胜。敌人是僵尸与《山海经》妖邪，Boss 为旱魃与尸王。

## 快速开始

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run test       # 单元测试（vitest，27 个用例）
npm run build      # 生产构建（输出 dist/）
npm run preview    # 预览生产构建
```

## 玩法

- **WASD / 方向键** 移动，不需要瞄准与射击，所有武器自动索敌
- 击杀妖邪掉落**魂魄**升级：自动小幅成长（+1% 伤害/+3 生命），**三选一奖励挪到关卡切换**
- **M** 静音，**ESC** 暂停
- 两种模式：
  - **闯幽冥**：击杀数过关（第 1 境 10 个，随深度缓增），打满亮出 1~3 扇门（下行之路/补给站/小怪房/Boss 房/冥品商店），选门拿关卡奖励；无升级无魂魄，成长全靠过门抉择；主题从人间一路杀穿地府，每境独立场景
  - **无尽尸潮**：没有天亮没有门，Boss 每 5 分钟交替登场逐巡增强，死亡才结算
- 局末结算**铜钱**入账，去**鬼市**消费、去**地府银行**钱生钱

## 天地银行（金融系统）

主菜单进入，开户送 100 冥币。**冥币买不了任何东西**——只能：

- **炒地府 A 股**：孟婆汤业 / 判官笔业 / 黄泉高铁 / 阎罗电子，每局结算随机波动 ±30%，偶发财经快报大起大落
- **买地府理财**：孟婆汤基金（2局+12%）/ 六道轮回债（3局+22%）/ 枉死城地产（4局+40%，25% 违约腰斩）
- 按**每局浮动的汇率**（1 冥币 ≈ 6~18 文）换回铜钱去鬼市

终局目标：**弑神枪，鬼市标价 999,999 文**——枪出荡涤满屏。纯靠打仗攒钱几乎不可能，得让钱生钱。

## 鬼市（局外成长，分页商店）

- **闯关页 · 鬼面具**：闯幽冥专属人物强化，六种面具各 3 级（怒+伤/韧+甲/疾+速/血+上限/噬+击杀回血/贪+结算铜钱），买下常驻生效
- **无尽页 · 正常商店**：道途（职业）+ 宝珠 + 传说位

主菜单进入。只卖**局内拿不到**的独家内容，铜钱消费、localStorage 存档（初始送 200 文）：

**道途（职业，择一入世）——各拥招牌机制**

| 职业 | 价格 | 起手 | 机制天赋 |
|---|---|---|---|
| 茅山道士 | 免费 | 飞符 | 经验 +10% |
| 萨满 | 400 文 | 电符 | 闪电链连跳 +4 次且跳距更远 |
| 武士 | 400 文 | 关刀 | 范围 +30%/护甲+2；一扫三敌返还 30% 冷却 |
| 猎人 | 500 文 | 猎弓 | 灵犬宠物扑咬妖邪；犬杀猎物魂魄翻倍 |
| 术士 | 600 文 | 蚀魂咒 | 汲魂：咒杀回血、被咒者承伤 +25%、死后传染 |

**宝珠（机制道具，携带 ≤2）**：血珠（诛邪回血）· 雷珠（每 6 秒自动落雷）· 鬼珠（磁吸翻倍+经验）· 焰珠（受击反炸冲击环）· 风珠（移速+回复）

职业专属武器（电符/关刀/猎弓/蚀魂咒）与玄甲胄不会出现在局内升级池。

## 架构

```
src/
  core/    数学/RNG/空间网格/对象池 —— 零依赖基础设施
  data/    全部平衡数值：武器图鉴、法宝图鉴、妖邪图鉴、波次导演表、鬼市目录
  game/    纯 TS 逻辑层（不 import Phaser，可直接单测）：
           World 主循环（夜巡/无尽双时间轴）、武器/敌人行为策略注册表、
           升级抽卡池、属性结算、localStorage 存档
  render/  程序化贴图工厂（Canvas 2D，零外部素材）、WebAudio 合成音效
  scenes/  Phaser 场景：Boot / Menu / Market(鬼市) / Game / UI / LevelUp / Result / Pause
tests/     vitest 单元测试（41 个：网格、升级池、武器数值、双模式时间轴、鬼市存档、金币公式…）
```

分层红线：`core/` `data/` `game/` 不 import Phaser；渲染层只读取 World 的公开数组做画面同步。

### 扩展新内容

- **新武器**：在 `src/data/weapons.ts` 加一条数据（已有行为可复用），或新增一个策略函数注册进 `WEAPON_BEHAVIORS`
- **新怪物**：在 `src/data/enemies.ts` 加数据 + `src/data/waves.ts` 排进波次
- **调难度**：只改 `src/data/` 下的数值，不动逻辑

### 无头冒烟测试

URL 带 `?autotest` 会进入自动演示模式（自动走位/选卡），`&ff=秒数` 可先同步快进逻辑层再截图，用于 CI 或人工冒烟：

```
http://localhost:5173/?autotest&ff=310   # 直接看 5 分10秒的 Boss 战
```

## 上架 Steam 路径

当前为 Web 技术栈（Phaser 3）。发布桌面版时用 Tauri 或 Electron 包一层（`dist/` 即完整产物），即可产出 Steam 可用的 Win/Mac 构建。
